ENGINEERING & DEPLOYMENT ARCHITECTURE

End-to-End WSI & Active Learning Flow

High-throughput gigapixel whole slide processing integrated with a human-in-the-loop experience replay engine to eliminate catastrophic forgetting during incremental fine-tuning.

Input Source Whole Slide Image

.svs / .ndpi / .tiff gigapixel slide scans

→
Tiling Engine Sliding Window

512×512 tiles with 25% overlap & Otsu glass filter

→
Neural Core YOLOv8n Backbone

3.01M parameter AMP-accelerated inference

→
Boundary Suppression Global NMS

Re-projects local boxes and collapses overlaps

→
Active Learning Replay Buffer

Stratified historical sampling with 1.5× boost

Module 1 & 2

Sliding-Window WSI Inference

Extracts overlapping patches using tiffslide, quickly discards clear glass (>80% background threshold), maps tile coordinates to global slide coordinates, and performs vectorized global NMS (IoU = 0.45).

Module 3

Experience Replay Buffer

Prevents catastrophic forgetting during pathologist review cycles. Enforces a 4:1 historical-to-new ratio, stratifies across all 10 taxonomy classes, and boosts underrepresented rare blast types by 1.5×.

Module 4 & 5

Sandbox Inference & Review UI

Zero-configuration browser tool allowing hematopathologists to drop blood smear images, adjust confidence thresholds in real time, reposition bounding boxes, and save verified labels into the AL queue.

DIAGNOSTIC HEMATOPATHOLOGY CONTEXT

WHO 2022 & FAB Morphological Criteria

Acute leukemia diagnosis requires rapid distinction between lymphoid and myeloid blast proliferation. Morphological triage flags urgent cases (>20% blast threshold) for expedited flow cytometry and cytogenetic confirmation.

Blast Entity FAB / WHO 2022 Correlate Cytological Characteristics Clinical Significance
Early Pre-B Pre-B Acute Lymphoblastic Leukemia Small-to-medium blasts, high N:C ratio, dense chromatin, inconspicuous nucleoli Urgent triage; responsive to pediatric B-ALL protocols
Pre B-ALL B-Lymphoblastic Leukemia / Lymphoma Heterogeneous size, clefted/irregular nuclear contours, variable cytoplasm Standard B-ALL presentation requiring immediate risk-stratification
Pro B-ALL Pro-B (CD10-) Precursor B-ALL Immature lymphoid morphology without mature lineage markers Often associated with KMT2A (MLL) gene rearrangements
Myeloblast Acute Myeloid Leukemia (AML) Large blasts, delicate chromatin, visible nucleoli, rare Auer rods, basophilic cytoplasm Critical medical emergency requiring induction chemotherapy
Benign / WBC Normal Hematopoietic Lineage Segmented neutrophils, band forms, mature lymphocytes, normoblasts Negative baseline controls preventing false alarm escalation

GETTING STARTED & INFERENCE PIPELINE

Reproducibility & Local Deployment

The trained model weights are committed directly to the repository and available via GitHub Releases for instant zero-dependency inference.

# 1. Clone repository
git clone https://github.com/abusuraihsakhri/blast-detection-algo.git
cd blast-detection-algo

# 2. Setup virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 3. Model weights are pre-loaded at data/models/active_model.pt
# Alternatively, download from GitHub Release v1.0.0:
# curl -L -o data/models/active_model.pt https://github.com/abusuraihsakhri/blast-detection-algo/releases/download/v1.0.0/active_model.pt

# 4. Launch the local Human-in-the-Loop review UI
python app.py
# Server starts at http://127.0.0.1:8000 with interactive drag-and-drop inference

# 5. Execute WSI sliding-window inference on a whole slide scan (.svs / .tiff)
python inference_pipeline.py /path/to/slide.svs
